# Portfolio Starter

An independently deployable personal portfolio template for nontechnical artists at the Echoes from Afar workshop. Success is a participant editing one Markdown file, seeing their work, and publishing their own copy.

Pinned reference: Cargo G937. Preserve desktop two-column browsing, opposing project panels, thumbnail index and information page. Mobile becomes a single column. White ground, black type, thin rules and minimal navigation. No promotional hero. Mode: Experience.

Static Astro, local content, no accounts or submissions. Public GitHub template repository; GitHub Pages is the default, Cloudflare Pages optional. The main Echoes platform and its private content systems are separate.
